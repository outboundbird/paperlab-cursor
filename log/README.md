# Session logs

Per-session handoff notes from PaperLab chats. Each file is a
self-contained context block: paste the fenced handoff block at the
bottom of a session file into a fresh chat to resume cleanly
without re-deriving prior decisions.

## Naming

`<YYYY-MM-DD>-<short-topic>.md`. Use the date of the session, not
of the commit landing.

## Why this folder

Cursor's chat history is per-machine and per-project, and the
`agent-transcripts/` JSONL files are verbose. These hand-written
summaries are the canonical "what we decided and why" record across
sessions.
